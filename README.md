# PLUM — прототип блока «Кухня»

Кликабельный прототип для согласования бизнес-логики, ролей, расчётов и интерфейса блока «Кухня» перед интеграцией в основной проект PLUM.

Прототип не является отдельной производственной системой и не должен переноситься в PLUM целиком. При интеграции согласованные сценарии и внешний вид необходимо сопоставить с существующими компонентами, моделями, API и правами доступа основного проекта.

## Локальный запуск

Проект не требует сборки:

```powershell
python -m http.server 4191
```

После запуска откройте `http://127.0.0.1:4191/`.

## Проверки

Автоматизированные браузерные сценарии находятся в папке `tools/` и используют Playwright.
